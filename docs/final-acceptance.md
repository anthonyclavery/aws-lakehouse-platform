# Final V1 demonstration acceptance

The operator-led, on-demand V1 demonstration is accepted on AWS in eu-west-3 on 2026-11-04. The [native evidence](evidence/final-acceptance-2026-11-04.json) and [readable AWS report](examples/demo-aws-report.md) cover actual managed jobs, temporary analyst reads, complete comparisons and cleanup. Follow the [single-entry-point runbook](demo-runbook.md) to use the compact demonstration.

Full-history pricing uses the shared tariff engine. Independent integer index/interval derivation and typed-row SHA-256 comparisons supplement its business tests. SHA-256 uses every declared table field separated by a pipe and a trailing newline, ordered by reading/end timestamp within each meter; accepted source fields contain no separator. Athena hashes use the same UTC seconds/integer encoding. Reference comparisons use the documented operational field projection, not arbitrary extra source fields. Gold comparisons retain exact fingerprints and the existing numeric tolerance; observed fingerprints matched with zero numeric error.

The 200-site fixture is generated by the existing reference/index generator and flattened into one manifest-backed index file for the normal launcher. Its local oracle streams intervals/segments and aggregates results, rather than retaining the entire history/segment set. The published generator's complete output matched a separately executed generation/oracle. A unit test also compares streaming aggregation with the existing complete calculator.

## Cold start, teardown and cost

The first cold start stopped at role assumption before source publication or job submission. The failed workspace and successful cleanup were retained. Deployment now performs up to thirteen credential-only readiness probes, five seconds apart (up to sixty seconds of explicit waiting), verifying the actual dedicated role before marking the deployment ready. Only AccessDenied readiness failures are retried; managed jobs are not resubmitted. The complete fresh run passed after an observed readiness wait.

The first full-domain audit exposed a qualification identity error: the operator intentionally lacks GetDataAccess for governed Gold. The qualifier now keeps operational reads on the operator and verifies/uses actual analyst credentials for Gold. No IAM rights were expanded and the successful processing jobs were not rerun. The failed read was retained, and a regression test checks the two query clients separately.

Native guarded cleanup succeeded for the cold-start attempt and both successful deployments. The existing bounded LF self-revocation recovery remained unchanged. Independent checks cover data-plane absence, temporary identities/policies, final scoped Gold grants/registrations, persistent identities, state versioning and original LF settings. An additional native empty cleanup succeeded. Enabled data-plane convergence was checked before destruction and persistent-bootstrap convergence afterwards. The daily schedule was kept enabled and its complete configuration was unchanged.

Observed usage at current regional prices gives a planning model of **USD 1.5847** for this acceptance, including explicit unmetered allowances. This is not a settled invoice. Read the [cost assumptions, idle/monthly model and billing observations](cost-and-destruction.md).

The V1 deliverable is an operator-led CLI/Athena demonstration with reproducible evidence and controlled destruction. It does not establish a production SLA, a continuously deployed endpoint, tenant isolation or universal performance results. Schema version 2 is quarantined rather than migrated. Existing benchmark limits and the explicit reference-change/full-refresh contract remain applicable.
